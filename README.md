# offsetcert-lab — 凸多面体的精确平面偏移证书

**一句话承诺**：3 个有理法向凸多面体 × 6 档 d∈{0.1,0.25,0.5,0.75,1,2} mm，18/18 个偏移体
在 BigInt 有理数下 **100% 水密且满足凸性证书**；体积对 d 恰为三次多项式，**63/63 个独立 d 点
精确复核 0 误差**；1e-6…1e6 五个尺度 **15/15 逐坐标精确等变**，全库核心 **零 epsilon**。
对照基线 `baseline/naive.mjs`（Float64 + 固定 `AREA_EPS=1e-9`）在 1e-6 尺度把 **3/3 形状的全部面**
判为退化而拒绝，而精确核心照常给出精确体积。

Upstream: none

## 怎么跑（三条命令，无依赖）

```bash
node tools/gen-sample.mjs     # 重建 data/shapes.json（固定种子、字节确定）
node bench/verify.mjs         # 38 条断言，全过 exit 0
node bench/bench.mjs          # 7 个样本 + 冷启动，写 bench/result.json
python3 -m http.server 4173   # 打开 http://localhost:4173
```

页面用 `three@0.160.0` 的 importmap（版本写死），只负责渲染与拖动；所有数字由
`src/core.mjs` 在浏览器里用 BigInt 有理数重算，和 node 端是同一个模块。

## 证据（真实运行，`bench/result.json`）

| 指标 | 结果 |
| --- | --- |
| 偏移体水密 + 凸性 | **18/18**（3 形状 × 6 档 d），最小边数 8 |
| 三次体积律独立复核 | **63/63 点**，最大误差 **0**（精确有理数，不是浮点容差） |
| cube | `V(d) = (2+2d)³ = 8 + 24d + 24d² + 8d³`，与闭式逐系数相等 |
| pyramid | `V(d) = (1+3d)³ = 1 + 9d + 27d² + 27d³` |
| chamfer-prism | `95/12 + 283/12·d + 70/3·d² + 23/3·d³`，21 点复核 0 差 |
| 尺度不变性 | 1e-6 / 1e-3 / 1 / 1e3 / 1e6 **15/15 精确等变**（最小体积 2.2e-18） |
| 独立 oracle | 半空间 vs 四面体定向，**60,000 点 0 分歧**，边界 490 点单列 |
| 基线 @1e-6 | **3/3 形状全部面 < AREA_EPS 被拒**；精确核心 3/3 水密 |
| 基线 @unit | 可用，体积相对误差 **1.67e-16**（诚实：基线在单位尺度是准的） |
| 性能 | 精确证书 **0.2095 ms/偏移体**（中位）；朴素 Float64 0.0043 ms/偏移体，冷启动 16.248 ms |
| 断言 | **38 passed / 0 failed** |

性能样本 7 个（每样本 30 轮 × 18 个偏移体），中位 113.1 ms、p95 195.1 ms、
相对标准差 28.9%。**为什么标准差大**：本机 4 核与另外两个团队共享，7 个样本里出现
1–2 个调度/GC 尖峰；因此同时报告 min/median/p95 与冷启动，不用单个最小值充数。
朴素基线 48.7× 更快是预期代价：它用 Float64 和绝对 epsilon，精确核心用 BigInt 有理数。

## 本轮创新

**首次把「凸多面体平面偏移」做成可现场复算的精确证书链**：偏移只移动支持平面常数
`c → c+d`，每个顶点用 3 个相邻平面做 BigInt Cramer 求解；由于顶点是 d 的仿射函数、
体积是顶点的三次型，`V(d)` 必为三次多项式——本项目在 4 个精确有理点插值，再在 21 个
独立 d 点逐点核对，误差恒为 0。这比「浮点拟合 + 容差」强的地方在于：
**阈值不存在**，所以 1e-6 到 1e6 五个尺度是同一个证明，不需要按尺度调参。
台账里 `facet-atlas-lab` 做整数格点面片、`symplane-lab` 做对称面搜索，都没有把
平面偏移的体积律与尺度等变性做成一条可复算的链。

## 已知限制（必须读）

- **核心没有绝对阈值**：`src/core.mjs` 全部用 BigInt 有理数，不含 `EPS`。它能处理的
  形状必须满足「支持平面法向是**有理单位向量**」（3-4-5 这类）；长度非完全平方的
  法向会显式抛错，不会静默降级。
- **基线的两个绝对阈值已披露**：`EPS=1e-9`（平面归属/主元）与 `AREA_EPS=1e-9`（面积）。
  有效尺度实测为 **≥1e-3**：1e-6 尺度下立方体面面积 4e-12 < 1e-9，6/6 面被拒。
  这正是 11-02 定档要求的披露方式，而不是把失败藏进「环境问题」。
- **只证凸体**：自交检测用凸性证书（每顶点满足所有平面、每面严格分离）代替一般
  网格自交；凹网格不在承诺范围内。
- **页面需要浏览器能访问 unpkg**；离线打开会没有 three.js，但 `bench/*` 与
  `src/core.mjs` 完全不依赖网络。
- 体积单位：示例按 mm 缩放（×10），README 中的 d 单位为 mm，`data/shapes.json`
  保存 unit-scale 有理数。

## 项目结构

```
src/core.mjs          # 纯计算：Q 有理数、偏移、体积、水密/凸性/三次律/尺度/四面体 oracle
main.js               # 渲染 + 拖动，只消费 core 输出
index.html            # 唯一入口，写死版本 importmap
tools/gen-sample.mjs  # 确定性示例数据生成（固定种子 LCG）
baseline/naive.mjs    # Float64 + 绝对 EPS 基线（诚实报告其尺度窗口）
bench/verify.mjs      # 38 条断言
bench/bench.mjs       # 7 样本 + 冷启动 → bench/result.json
```
